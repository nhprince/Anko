# Changelog

All notable changes to this project are documented here.
Format loosely follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
versions follow [SemVer](https://semver.org/).

## [1.0.1] - 2026-09-25
### Added
- Windows installer (Inno Setup) with Start Menu / Desktop shortcuts and an uninstaller.

## [1.0.0] - 2026-09-25
### Added
- Initial release: natural textbook display, 13 calculation modes (Calculate, Statistics,
  Distribution, Spreadsheet, Table, Equation, Inequality, Complex, Base-N, Matrix, Vector,
  Ratio, Math Box), SHIFT/ALPHA keypad, CALC/SOLVE, session persistence, dark/light themes.
