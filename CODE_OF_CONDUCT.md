# Code of Conduct

This project follows a simple standard: be respectful, be constructive, assume good faith.

- Disagreement about code or design is fine and expected; personal attacks are not.
- No harassment, discriminatory language, or trolling in issues, PRs, or discussions.
- Keep criticism focused on the work, not the person.

Reports of unacceptable behaviour can be sent to the maintainer via a private message on
GitHub or the contact method listed on the maintainer's profile. Maintainers may remove
comments, close issues/PRs, or block contributors who violate this standard.

This is a lightweight adaptation of the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/).
